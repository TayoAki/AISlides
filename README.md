# Roomwright

AI design for interiors, exteriors and gardens. Upload a photo of a room, facade or yard and get photoreal redesigns — restyle, virtual staging, decor staging, declutter, paint, material swaps, sky replacement, sketch-to-render, precision edits, style transfer, text-to-design and a furniture creator — while the walls, windows and layout stay put.

Built with Next.js 16 (App Router), React 19, Tailwind CSS 4, SQLite (better-sqlite3) and sharp. Promo scenes are authored with [Flute](https://github.com/webprodigies-org/flute).

## What's in the box

- **Marketing site** (`src/app/(marketing)`): home, pricing, 15 use-case pages, 6 audience pages, 18 feature pages (4 marked coming soon), 3 inspiration pages, 5 free-tool pages, blog, help desk, API page and API docs, enterprise, affiliate, white-label widget, changelog, release notes, company and legal pages, `sitemap.xml` and `robots.txt`. Page copy lives in typed data files under `src/content/`.
- **Studio app** (`src/app/(studio)/app`): email/password accounts, upload (drag, click or paste) or sample photos, 12 tools with per-tool options, async render queue, before/after comparison, download, "generate another", "try another style", "refine this result", design history, account settings, API keys and account deletion. No paywall: every account gets `FREE_DAILY_RENDERS` renders per UTC day.
- **Public REST API** (`/api/v1/renders`): Bearer API keys, multipart or JSON/base64 input, polling, authenticated downloads. Documented at `/docs/api`.
- **Admin** (`/app/admin`): form submissions and basic stats for emails listed in `ADMIN_EMAILS`.

## Run locally

```sh
npm ci
cp .env.example .env.local   # optional; defaults work
npm run dev                  # http://localhost:3000
```

Without an AI key the app runs in **demo mode**: renders are labeled color-grade previews (never passed off as AI output) so the whole loop can be tested. Add `REPLICATE_API_TOKEN` (or `OPENAI_API_KEY`) to get real redesigns.

## Checks

```sh
npm run typecheck

npm run check:content        # schema limits, links, image keys, no unverifiable claims
npm run build && FREE_DAILY_RENDERS=8 npm start &
BASE_URL=http://127.0.0.1:3000 npm run test:e2e   # full product loop: signup → render → API → limits → delete
```

## Deploy (Railway)

1. Create a service from this repo (Railpack/Nixpacks detects Next.js; `railway.json` sets the start command and `/api/health` health check).
2. Attach a **volume** mounted at `/data` and set `DATA_DIR=/data` (the SQLite DB and images live there).
3. Set `NEXT_PUBLIC_SITE_URL=https://${{RAILWAY_PUBLIC_DOMAIN}}`, `FREE_DAILY_RENDERS`, `ADMIN_EMAILS`, and one AI key.
4. Generate a domain.

## Promo videos with Flute

Scenes live in `src/flute/scenes` (recipe JSON + a component that wraps the real UI in `<Surface>`). Recipes are generated by `scripts/flute-recipes.mjs`.

| Scene | Shot |
| --- | --- |
| `hero-survey` | Oblique pass across the landing hero, headline to studio card |
| `studio-panel` | Travels down the real studio settings to Generate |
| `tools-plating` | The twelve tool cards settle into the toolkit grid |
| `pricing-survey` | Survey along the plans, Free to Enterprise |
| `cta-endcard` | Slow push toward the closing call to action |

```sh
npm run flute:recipes        # regenerate recipes + catalog
npm run dev                  # open http://localhost:3000/flute (development only)
npm run promo                # export every scene, then join them into promo/roomwright-promo.mp4
SKIP_EXPORT=1 npm run promo  # only re-join existing clips
```

A single scene: `npx flute export --url 'http://127.0.0.1:3000/flute?flute-preview=1&flute-scene=hero-survey' --output promo/hero-survey.mp4 --fps 30 --width 1920 --height 1080`. Export needs FFmpeg and Playwright's Chromium (`npx playwright install chromium`).

Page surfaces are 1920px wide so the camera always travels over real page; Flute's content wrapper sizes to its children, so give the page an explicit height rather than `h-full`. After changing a scene's camera, refresh its library thumbnail with `npx flute snapshot --scene <id> --url http://localhost:3000`.

Once an AI provider is connected, run `scripts/generate-showcase.mjs` to add real before/after pairs to the home page, then re-export the promo.
